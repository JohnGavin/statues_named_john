# Subjects worth looking up on Wikidata

Subjects worth looking up on Wikidata

## Usage

``` r
candidate_subjects(text)
```

## Arguments

- text:

  Character vector of subject/name text.

## Value

Unique subjects X, in first-seen order, from text that starts with an
object prefix (see \[extract_subject()\]); X of fewer than 3 characters
is dropped.
